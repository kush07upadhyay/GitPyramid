# Getting help

| I want to | Go to |
| :--- | :--- |
| Ask how something works, or share an idea | [Discussions](https://github.com/kush07upadhyay/GitPyramid/discussions) |
| Report a bug | [New issue](https://github.com/kush07upadhyay/GitPyramid/issues/new/choose), choose "Bug report" |
| Suggest a project for the registry | [New issue](https://github.com/kush07upadhyay/GitPyramid/issues/new/choose), choose "Suggest a brick" |
| Add a brick myself | [CONTRIBUTING](CONTRIBUTING.md#add-a-brick-in-10-minutes) |
| Report a security problem | [SECURITY](SECURITY.md) |
| Report a conduct problem | conduct@gitpyramid.com, see the [Code of Conduct](CODE_OF_CONDUCT.md) |
| Ask about sponsoring | [SPONSORSHIP](docs/SPONSORSHIP.md), then sponsors@gitpyramid.com |

This is a volunteer project. Questions asked in public help the next person, so please prefer
Discussions over private messages. We read everything, and we answer as time allows.
